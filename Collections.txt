LinkedList
==========

if ArrayList Already works, why does java provide LinkedList


An ArrayList is internally based on a resizable array

ArrayList

[ Rahul ][ Priya ][ Arjun ][ Sneha ][ Kiran ]
    0       1        2        3        4

but the Linked List works differently 


LinkedList

[ Rahul ] → [ Priya ] → [ Arjun ] → [ Sneha ]

Each Element is connected to another element 

inside an LinkedList each element we call it as A NODE

A Node basically contains the following

+---------+---------+
|  Data   |  Link   |
+---------+---------+

[ Rahul ] → [ Priya ] → [ Arjun ] → [ Sneha ]

Rahul is the data
there is a link to Priya

Priya is the data
there is a link to Arjun ....

this is the idea behind the linked list


important Point to remember

Just like arraylist linkedlist also implements the List interface 

			          List
           			 /    \
          			 /      \
  			 ArrayList    LinkedList

therefore both can perform some common list Operations
add()
get()
set()
remove()
contains()
size()


Why Linked List only .?

Assume you have the following

[ Rahul ][ Priya ][ Arjun ][ Sneha ][ Kiran ]

now you want to inset Kiran between Priya and Arjun

with Array Based Liked List we will do the following

Before:

Rahul | Priya | Arjun | Sneha
              ↓
we need to shift all the values from Arjun to end so that we can insert the new Value

After:

Rahul | Priya | Kiran | Arjun | Sneha


Since Liked List uses the Concept of nodes and linking this will be easy
 
[ Rahul ] → [ Priya ]  [ Arjun ] → [ Sneha ]
		|	   |	
		[Kiran]  -->



[ Rahul ] → [ Priya ]  → [Kiran]  → [ Arjun ] → [ Sneha ]

addLast()
